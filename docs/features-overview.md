# Помощник настройки рабочего места для ЭП: что уже реализовано и что можно добавить

Состояние на версию **1.7.1** (`<Version>` в `src/SetupAssistant/SetupAssistant.csproj`, ветка `master`, коммит `0deb50e`).

Документ — карта возможностей: что есть в приложении, где это лежит в коде, какие ограничения осталось и что можно добавить. Пошаговые инструкции по установке и сборке — в [README.md](../README.md), история версий — в [CHANGELOG.md](../CHANGELOG.md), справочник следов СКЗИ — в [crypto-cleanup-research.md](crypto-cleanup-research.md).

> Документ составлен по исходному коду, README, CHANGELOG и памяти проекта. Приложение на Windows в этой работе не запускалось: поведение, которое зависит от реестра, msiexec и установщиков производителей, описано по коду и документации проекта. Оно не перепроверено на машине.

---

## 1. Коротко о приложении

- **Назначение.** Автономная программа для диагностики, установки, настройки и удаления компонентов рабочего места электронной подписи: КриптоПро CSP, КриптоПро ЭЦП Browser plug-in, драйверы Рутокен, Chromium GOST, плагины Контура и Госуслуг, расширения браузера, сертификаты.
- **Технологии.** WPF, .NET 8 (win-x64), MVVM на CommunityToolkit.Mvvm, внедрение зависимостей через Microsoft.Extensions.DependencyInjection, интерфейс на ModernWpf 0.9.6, PDF-отчёты на QuestPDF, PIN-коды через Pkcs11Interop, значок в трее через H.NotifyIcon.
- **Права.** Запускается только от администратора (`src/SetupAssistant/App_Manifest/app.manifest`).
- **Два режима.** Окно (по умолчанию) и командная строка без окна для GPO / SCCM (раздел 9).
- **Поставка.** Либо папка с `SetupAssistant.exe`, либо один файл `SetupAssistant-Full-<версия>.exe` с встроенными дистрибутивами (раздел 8).
- **Язык.** Только русский. Среда предполагается внутренняя, без доступа к магазину Chrome. Все дистрибутивы лежат локально, интернет нужен только для скачивания новых версий.

## 2. Экраны и разделы

Пункты меню в порядке, как они стоят в `src/SetupAssistant/MainWindow.xaml`:

| Раздел | Что делает | Главное |

| **Диагностика** | Полная проверка по группам | Фильтр «Только проблемы», счётчики, «Исправить» в строке, советы «что делать», копирование |
| **Настройка** | Мастер установки и проверки | Выбор компонентов, предварительная проверка, повтор шагов, отмена с откатом, перезагрузка с продолжением, сводка и отчёт |
| **Удаление** | Откат настройки и полная очистка СКЗИ | «Удалить», «КриптоПро», «КриптоПро с Континентом», режим «Полная очистка», предпросмотр найденного |

| **Настройки** (внизу меню) | Оформление и сведения | Тема, масштаб 100–150 %, повтор приветствия, сведения для поддержки, проверка обновлений расширений |

## 4. Диагностика

Проверки собраны в четыре группы (`src/SetupAssistant/Services/DiagnosticService.cs`, `Models/ComponentCatalog.cs`):

- **КриптоПро:** CSP, провайдеры (типы 75, 80, 81), считыватели, ключевые контейнеры, Browser Plugin, COM-компонент CAdESCOM.
- **Браузеры и плагины:** браузеры (Chromium GOST, Chrome, Edge, Яндекс.Браузер: наличие и версия), native messaging-хосты (`kd.nc`, `ru.cryptopro.nmcades`, `ru.rtlabs.ifcplugin`), Контур.Плагин, Плагин Госуслуг, расширения браузера, управление компьютером (домен или MDM).
- **Носитель и сертификаты:** драйверы Рутокен и JaCarta, подключённый носитель, сертификаты УЦ, сертификаты электронной подписи (назначение ключа, EKU, политики, цепочка доверия).
- **Система:** Континент-АП.

Статусы:

- **Ок** — в порядке.
- **Предупреждение** — компонент установлен, но его версия ниже рекомендуемой, либо проверка установленного не прошла.
- **Ошибка** — проблема, которая мешает работе.
- **К сведению** — не установлено, носитель не подключён, компьютер не в домене. Это не ошибка: на каждом рабочем месте нужен не весь набор.
- **Не проверялось / Пропущено** — служебные статусы.

Экран умеет фильтровать «Только проблемы», показывает счётчики, кнопку «Исправить» в строке (запускает мастер только для этого компонента) и совет из `Helpers/HelpAdvisor.cs`. Советы есть и у шагов мастера с проблемой. Пример: почему расширения не применяются вне домена.

## 5. Мастер настройки

Состав шагов собирает `Helpers/SetupPlan.cs`. Его используют и окно, и режим `--silent`.

1. Установка КриптоПро CSP → проверка
2. Установка КриптоПро Browser Plugin → проверка
3. Установка драйвера Рутокен → проверка
4. Установка Chromium GOST → проверка
5. Установка Контур.Плагина → проверка
6. Установка Плагина Госуслуг → проверка
7. Континент-АП: установка и проверка, а также импорт профиля и сертификатов. Шаги появляются, только если дистрибутив задан в `Config.json`
8. Установка расширений браузера
9. Установка сертификатов УЦ. Появляется, только если список `CaCertificates` не пуст
10. Установка сертификата с носителя (ожидание носителя до 60 секунд)
11. Повторная диагностика

Возможности:

- **Предварительная проверка** (`Services/PreflightService.cs`): права администратора; свободное место (не меньше 1 ГБ, предупреждение до 3 ГБ); наличие дистрибутивов; доступ к серверам загрузки; ожидающая перезагрузка Windows; занятость Windows Installer и зависший установщик.
- **Выбор шагов.** Флажки; кнопки «КриптоПро» и «КриптоПро с Континентом»; «Выбрать недостающее»; «Переустановить установленные» (без неё уже установленное пропускается); «Повторить» у шага; «Повторить неудачные»; скрытие завершённых шагов.
- **Проверка после установки.** Каждая установка имеет парный шаг проверки. Если проверка не прошла сразу после установки или Windows ждёт перезагрузки, шаг помечается «нужна перезагрузка», а не провалом.
- **Перезагрузка и продолжение.** «Перезагрузить и продолжить» ставит однократный автозапуск `--resume` в `HKCU ... RunOnce`. После входа в систему приложение само определяет, что осталось сделать.
- **Отмена с откатом** (с 1.6.0). Останавливает установщик вместе с дочерними процессами и удаляет недокачанный файл. Откатывает только то, чего не было до запуска: КриптоПро CSP, плагины, драйвер Рутокен, Континент-АП. Chromium GOST, политика расширений и сертификаты не откатываются, они перечисляются в итоге.
- **Зависший установщик** (с 1.6.4). Если КриптоПро зависает на драйвере `CProCtrl` и три минуты нет вывода, шаг завершается с сообщением «нужна перезагрузка». Остальные установки откладываются до перезагрузки.
- **Ожидание носителя.** 60 секунд с обратным отсчётом и кнопкой «Пропустить».
- **Итог.** Сводка по шагам и экспорт отчёта в PDF или TXT.

## 6. Удаление и полная очистка

### 6.1. Откат настройки

Реализация: `Services/UninstallService.cs`, раздел `Uninstall` в `Config.json`.

- **Порядок** обратный установке: Континент-АП вместе с eXtended Container и Код Безопасности CSP (если есть), Контур.Плагин, Плагин Госуслуг, КриптоПро ЭЦП Browser plug-in, драйверы Рутокен, КриптоПро CSP.
- **Поиск.** Программы ищутся в «Программах и компонентах» (HKLM и HKCU) по названиям. MSI удаляется через `msiexec /x` с `MSIRESTARTMANAGERCONTROL=Disable`, EXE — командой из реестра плюс `Args`.
- **Результат** каждого шага определяется по реестру, а не по коду возврата.
- **Перед удалением** закрываются процессы браузеров и плагинов.
- **Добивка пустых остатков.** Удаляются пустые папки и ветки реестра КриптоПро и Security Code, а также мёртвые ProgID `CAdESCOM.*`. Непустое не трогается.
- **Политика расширений.** Удаляются только записи, которые ведут на `updates.xml` самого приложения. Чужие записи остаются.
- **Кнопки:** «Удалить» (всё найденное, включая Континент-АП), «КриптоПро» (без Континента), «КриптоПро с Континентом».
- **Не трогается никогда:** ключи, ключевые контейнеры, содержимое токена, ветка `HKCU\SOFTWARE\Crypto Pro`, пока в ней есть значения.

### 6.2. Полная очистка СКЗИ

Флажок «Полная очистка ПК от СКЗИ» на экране «Удаление» или `--uninstall --full`. Цель: убрать и следы, которые штатные деинсталляторы оставляют после сбоев. Карта следов и обоснование — в [crypto-cleanup-research.md](crypto-cleanup-research.md).

1. **Точка восстановления Windows**, если защита системы включена.
2. **Резервная копия** в `Logs\FullCleanup-<дата>`: ключевые контейнеры (реестр и HDIMAGE во всех профилях, в `.reg`), сертификаты КриптоПро (`.cer`), серийный номер CSP.
3. **Контейнеры** удаляются только после успешной копии и отдельного подтверждения. По умолчанию остаются. Без окна — ключ `--delete-containers`. Токены не затрагиваются никогда.
4. **Штатное удаление** программ (как в 6.1). Сертификаты КриптоПро из «Личное» удаляются, их копия лежит в папке отчёта.
5. **Глубокая очистка.** Своих веток реестра, провайдеров и OID CryptoAPI, описаний носителей, CNG и ГОСТ-шифронаборов TLS, пакета LSA `cpsspap`, драйвера `CProCtrl`, COM CAdESCOM, native messaging-хостов, хранилища `CryptoProTrustedStore`, папок и файлов в Program Files, ProgramData, профилях и System32. Файлы в системных папках выбираются по сведениям о производителе внутри файла, а не по маске имени.
   - Если программы ещё не удалены или Windows Installer занят, очистка откладывается до перезагрузки. Приложение запускается само (`--resume`) и доделывает.
   - Если установлены другие программы КриптоПро или «Актив» (например, КриптоПро PDF), глубокая очистка не выполняется.
6. **Отчёт.** `report.txt` с результатом по каждой записи. Перед каждым изменением раздел реестра сохраняется в `registry\removed-<время>.reg`.
7. **Расширения в профилях браузеров** только перечисляются для ручного удаления. Браузер хранит их сам, а файлы профиля защищены подписью.

Чем очистка не трогает чужое:

- Код Безопасности CSP и Континент-АП удаляются только кнопками «Удалить» и «КриптоПро с Континентом», и только их собственные следы. Secret Net Studio и Jinn-Client из той же папки остаются.
- Общие списки Windows (LSA, CNG) правятся по элементу, а не по разделу.
- Общие ГОСТ-описания остаются, если на компьютере есть другой ГОСТ-криптопровайдер.

Предпросмотр без изменений: `--cleanup-preview файл.txt`.

## 7. Сертификаты, тест подписи и PIN-код

- **Сертификаты** (`Services/CertificateService.cs`). Читаются из хранилищ Windows. Проверяются назначение ключа, EKU, политики и цепочка доверия. **Отзыв не проверяется** (`RevocationMode = NoCheck`): для ГОСТ нужны CRL из сети УЦ. Срок действия предупреждает за 30 дней (`CheckSettings.CertificateExpiryWarningDays`). Экран следит за подключением носителя и показывает уведомление.
- **Сертификаты УЦ** (`Services/CaCertificateService.cs`). Импортируются только из `Config.json` и только при совпадении SHA-1 отпечатка, действующем сроке и признаке УЦ. По умолчанию список пуст, так как у заказчика сертификаты УЦ ставятся политиками.
- **Тест подписи** (`Services/SignatureTestService.cs`). Подписывает тестовые данные через КриптоПро CAdESCOM так же, как браузерный плагин. Этапы видны по отдельности, поэтому сбой сразу показывает место, где он случился. Советы — из `HelpAdvisor`.
- **PIN-код носителя** (`Services/TokenPinService.cs`). Смена PIN пользователя или администратора как в «Панели управления Рутокен». Работает через PKCS#11: `rtPKCS11ECP.dll` (Рутокен) и `jcPKCS11-2.dll` (JaCarta) из System32. Введённые значения проверяются до обращения к носителю, чтобы не тратить попытку. Заблокированный PIN показывается предупреждением, разблокировка делается в панели Рутокен. PIN нигде не сохраняется.

## 8. Обновления и поставка

### 8.1. Что загружается при установке

- **Chromium GOST** и **Контур.Плагин** (`DownloadUrl` в `Config.json`) при установке скачиваются с сайта, если есть связь. Иначе используется локальный файл.
- **КриптоПро CSP**, **Browser Plugin**, **Плагин Госуслуг**, **драйвер Рутокен** ставятся из локальных файлов в `Appendices`.
- Для скачанного файла проверяется подпись Authenticode и то, что издатель содержит `ExpectedSigner`.

### 8.2. Режим `--update-distributions`

Реализация: `src/SetupAssistant/Updater/`. Запускается на машине с интернетом, от администратора.

- **Расширения.** Версии сверяются с сервером обновлений Chrome. Новый `.crx` скачивается, а если сервер отдаёт SHA-256, контрольная сумма проверяется.
- **Дистрибутивы.** Проверяются и обновляются КриптоПро ЭЦП Browser plug-in, Chromium GOST, Контур.Плагин, Плагин Госуслуг, драйвер Рутокен. Новый файл принимается, только если подпись действительна и издатель совпадает с `ExpectedSigner`. КриптоПро CSP зафиксирован и не обновляется.
- **Безопасные правки `Config.json`.** Перед правкой создаётся `Config.json.bak`. Правка точечная, комментарии сохраняются.
- **Ключи:** `--check` (только проверить), `--prune` (удалить старые версии), `--prune-only` (только удалить старые `.crx`, без сети).
- **Уведомление при запуске.** Если есть интернет, приложение сообщает о новых версиях расширений. То же делает кнопка в «Настройках».

### 8.3. Один файл exe

`tools/Build-SingleExe.ps1` (нужен PowerShell 7) собирает `dist/SetupAssistant-Full-<версия>.exe`.

- Конфигурация и папка `Appendices` дописываются в конец exe.
- Приложение распаковывает файлы только когда они нужны, в `%ProgramData%\SetupAssistant\Payload\<id сборки>`. Кэш предыдущих сборок удаляется при запуске.
- Файл `Config\Config.json` или дистрибутив рядом с exe имеет приоритет над встроенным. Так конфигурацию меняют без пересборки.
- Журнал пишется в папку `Logs` рядом с exe.

## 9. Режимы командной строки

Нужны права администратора. Вывод печатается в консоль, из которой запущено приложение, или в файл при перенаправлении. Результат попадает и в журнал.

| Команда | Что делает |
|---|---|
| `SetupAssistant.exe --check [--report файл]` | Проверка рабочего места, ничего не меняет |
| `SetupAssistant.exe --silent [--reinstall] [--with-token] [--report файл]` | Установка и настройка без вопросов. Шаг с носителя выполняется только с `--with-token` |
| `SetupAssistant.exe --uninstall [--kontinent-only]` | Откат настройки. Chromium GOST остаётся. `--kontinent-only` удаляет только Континент-АП и КБ CSP |
| `SetupAssistant.exe --uninstall --full [--delete-containers]` | Полная очистка. Контейнеры удаляются только с ключом и после резервной копии |
| `SetupAssistant.exe --cleanup-preview файл.txt` | Записывает, что удалит полная очистка, ничего не меняя |
| `SetupAssistant.exe --update-distributions <папка> [--check] [--prune] [--prune-only]` | Обновление расширений и дистрибутивов (нужен интернет) |
| `SetupAssistant.exe --support-bundle файл.zip` | Пакет для поддержки без сертификатов |
| `SetupAssistant.exe --resume` | Продолжение после перезагрузки (запускает окно) |
| `SetupAssistant.exe --help` | Справка |

Коды возврата: `0` — всё в порядке (недостающие компоненты и «не в домене» — к сведению); `1` — есть предупреждения; `2` — есть ошибки; `3` — установка невозможна (предварительная проверка); `4` — неверные аргументы.

Режимы без окна сами компьютер не перезагружают. Пример задачи Планировщика Windows с проверкой по `--check` не добавлен в проект.

## 11. Журнал, отчёты и пакет для поддержки

- **Журнал.** Файлы `Logs\setup-assistant-<дата>.log`, хранятся 30 дней. Для установщиков MSI пишется подробный журнал `msi-*.log` (`msiexec /l*v`) рядом с журналом приложения. В журнале можно фильтровать по уровню, искать, следить за новыми записями и копировать строки.
- **Отчёт.** PDF (QuestPDF, лицензия Community) или TXT. Сохраняется из окна или через `--report`.
- **Пакет для поддержки** (`Services/SupportBundleService.cs`). Один zip: журналы за 7 дней, диагностика, сведения о системе, конфигурация. Сертификаты добавляются только с вашего согласия, в режиме командной строки не добавляются вообще. PIN-кодов, ключей и содержимого токена в пакете нет.
- **Журнал полной очистки.** Папка `Logs\FullCleanup-<дата>` с резервной копией контейнеров, сертификатами, `report.txt` и `.reg`-файлами удалённых разделов.

## 12. Интерфейс и удобство

- **Оформление.** Светлая и тёмная тема, Mica на Windows 11 (при высокой контрастности Windows Mica отключается), масштаб интерфейса 100, 115, 130 или 150 %.
- **Клавиатура.** `Ctrl+1…9` — разделы по порядку меню, `F5` — обновить страницу, `Esc` — закрыть окно ожидания.
- **Трей и панель задач.** Значок в области уведомлений с меню «Открыть окно» и «Выход». Кнопка на панели задач мигает и становится жёлтой, когда приложение ждёт действия пользователя. Если окно свёрнуто, уведомление Windows сообщает о завершении.
- **Уведомления.** Успехи показываются тостами, модальные окна — только для ошибок и подтверждений. Закрытие окна во время установки или удаления требует подтверждения.
- **Окно перезагрузки.** Предлагает «Перезагрузить сейчас» (через 30 секунд, отменяется `shutdown /a`) или «Позже». По умолчанию выбрано «Позже».
- **Доступность.** У основных элементов заданы имена для экранного диктора. Есть скелетоны при загрузке и пустые состояния.
- **Значок приложения.** Щит с галочкой на синем квадрате, `src/SetupAssistant/Resources/AppIcon.ico`. Рисует его `tools/Make-AppIcon.ps1`.

## 13. Архитектура и структура кода

| Папка (`src/SetupAssistant/`) | Содержимое |
|---|---|
| `App.xaml.cs` | Точка входа и регистрация всех сервисов и ViewModel (внедрение зависимостей). В режиме без окна диалоги заменяются на `SilentDialogService` |

| `Services/` и `Services/Interfaces/` | Около 30 сервисов, по одному на область: реестр, система, КриптоПро, браузеры, расширения, токены, сертификаты, установщики, удаление, диагностика, отчёты, журнал, пакет поддержки и др. |

| `Helpers/` | Низкоуровневая работа: права и реестр (`SystemPrivileges`, `RegFileWriter`), поиск и удаление следов (`CryptoTraceScanner`, `CryptoTraceRemover`, `LeftoverCleanup`), резервные копии контейнеров, точка восстановления, перезагрузка и автозапуск, проверка подписи (`Authenticode`), распаковка данных из exe (`PayloadStore`), состав шагов (`SetupPlan`), советы (`HelpAdvisor`) |

## 14. Сборка, версии и выпуск

```bash
dotnet build src/SetupAssistant/SetupAssistant.csproj
```

```bash
dotnet publish src/SetupAssistant/SetupAssistant.csproj -c Release
```

```bash
pwsh tools/Build-SingleExe.ps1 -OutputDir <папка>
```

- **Публикация** даёт один self-contained exe для win-x64. Результат: `src/SetupAssistant/bin/Release/net8.0-windows/win-x64/publish/SetupAssistant.exe`.
- **Версия** задаётся одним значением, `<Version>` в `SetupAssistant.csproj`. Её же нужно поднять в `assemblyIdentity` в `app.manifest`. Приложение показывает версию вместе с хешем коммита, например `1.7.1 (0deb50e)`.
- **Выпуск.** Раздел в `CHANGELOG.md`. После слияния в `master` ставится тег `vГЛАВНАЯ.ДОПОЛНЕНИЕ.ИСПРАВЛЕНИЕ`.
- **Тестов нет.** Ни тестового проекта, ни CI-конфигурации в репозитории нет (раздел 16).

## 16. Что можно добавить

Оценка объёма — по коду, без проверки на стенде.

### 16.1. Функциональные пробелы

1. **Установка драйвера JaCarta** (объём: малый–средний). Сейчас есть только обнаружение и смена PIN. Нужно: дистрибутив и `Installers.JaCartaDriver.Path` с `Kind` и `SilentArgs`; шаги установки и проверки в `SetupStepKind`, `SetupPlan`, `SetupOrchestrationService.ExecuteStepAsync`; у `ComponentCatalog.Classify` сейчас для JaCarta `FixStep = null`. Образец — драйвер Рутокен. Дистрибутив нужно получить и положить в `Appendices`, как драйвер Рутокен.

2. **Проверка отзыва сертификатов CRL или OCSP** (объём: средний). Сейчас `CertificateService.cs` ставит `RevocationMode = NoCheck`. Нужно решить, что показывать, если УЦ недоступен: в закрытой сети CRL может быть недоступен.

3. **Политика расширений для Edge и Яндекс.Браузера** (объём: малый, но проверять на стенде). `Extensions.PolicyRegistryKeys` содержит только Chrome и Chromium GOST. Яндекс и Edge есть в `SupportedBrowsers`, но только для проверки. Нужно проверить, читает ли Яндекс политику Chromium.

4. **Самообновление SetupAssistant.exe** (объём: средний). Обновляются расширения и дистрибутивы, но не сама программа. `Updater` не проверяет версию самой программы. Можно использовать ту же схему с проверкой подписи.

5. **Дистрибутив Госплагина с native-хостом `gosuslugi.plugin`** (объём: зависит от наличия дистрибутива). Расширение «Госплагин» есть в `Extensions.Items`, но ни один дистрибутив проекта хост не ставит. Без хоста расширение не работает. Варианты: добавить дистрибутив или в диагностике и совете прямо написать, что нужно установить.

6. **Статус лицензии КриптоПро CSP** (объём: средний). Сейчас читается только серийный номер (`Helpers/KeyContainerBackup.cs`, `ProductID`). Срок и статус лицензии не показываются. Совет в `HelpAdvisor.cs:34` только просит ввести номер в «Панели управления КриптоПро».

7. **Политика «Доверенные узлы» CAdES-плагина** (объём: малый). Если понадобится, запись в `HKLM\Software\Policies\Crypto-Pro\CadesPlugin` по ADMX. Сейчас сознательно не делается (раздел 15).

8. **Неиспользуемая настройка `LogoPath`** (объём: очень малый). `Config.json:3` и `Models/AppConfig.cs:12`. Файла `Resources/logo.png` нет, в коде значение не читается. Либо удалить, либо подключить логотип.

9. **Поддержка других СКЗИ**, например ViPNet CSP (объём: большой). Приложение настроено только на КриптоПро. Очистка ViPNet не трогает, но и не настраивает его.

### 16.2. Качество и эксплуатация

10. **Автотесты** (объём: средний). Тестового проекта нет. Первыми стоит покрыть чистые функции: `CommandLineOptions.Parse`, `SetupPlan.Build` и `SelectOnly`, `ComponentCatalog.Classify`, `VersionService`, `LeftoverCleanup`, `ExtensionIdCalculator`, `RegFileWriter`, `HelpAdvisor`. Ошибка в поиске следов полной очистки опасна, поэтому разбор `CryptoTraceScanner` стоит покрыть особенно.

11. **CI-сборка** (объём: малый). Папки `.github` в репозитории нет. Сборка и `--help` могли бы проверяться на Windows-агенте. Сборка единого exe сейчас ручная.

12. **Централизованный сбор результатов** для парка ПК (объём: средний). `--report` пишет локальный файл, агрегации нет. Варианты: отчёт в сетевую папку или в журнал событий Windows.

13. **Журнал событий Windows** (объём: малый). Журнал пишется только в файл `Logs\...`. Для GPO и SCCM удобнее журнал событий: по нему удобно настраивать мониторинг.

14. **Локализация** (объём: большой). Строки захардкожены по-русски (`NeutralLanguage` = `ru-RU`). Нужна, только если появятся другие языки.

### 16.3. Удобство

15. **Расписание проверки** (объём: малый). `--check` уже возвращает коды 0–4. Можно добавить готовый пример задачи Планировщика и инструкцию.

16. **Экспорт сводки в CSV или JSON** для учёта рабочих мест (объём: малый). Сейчас отчёт только PDF и TXT (`ReportFormat`).

## 17. Расхождения в документации и что не проверено

- **Сертификаты КриптоПро при полной очистке.** В README раздел «Не удаляются никогда» говорит, что необязательный флажок удаляет сертификаты из «Личное» при полной очистке. По коду при полной очистке они удаляются **всегда**, их копия остаётся в папке отчёта (`Services/UninstallService.cs`, строки 74–75). Флажок относится к обычному удалению. README стоит выровнять.
- **Не проверялось на Windows:** сборка в этом документе не запускалась, мастер и удаление не выполнялись. Поведение описано по коду, README и CHANGELOG.
- **Не проверялось:** поведение Яндекс.Браузера с политикой Chromium (раздел 16, пункт 3).
